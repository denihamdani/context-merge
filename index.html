          🚀 Mulai Cepat

          1. Klik + New di panel Roles (atau Alt+N) untuk membuat persona AI.

          2. Klik + New di panel Context (atau Alt+K) untuk menambah bahan referensi.

          3. Pilih item dari sidebar → klik kanan → Add to Merge (atau Ctrl+Shift+M) → tekan Copy All (Alt+C) → paste ke AI.

          🧩 Konsep Dasar

          Role — Persona yang mendefinisikan karakter AI. Contoh: "Kamu adalah code reviewer yang teliti." Biasanya satu per interaksi.

          Context — Bahan referensi (spec, kode, dokumentasi). Boleh lebih dari satu per interaksi. Format Markdown.

          Preset — Kombinasi Role + Context yang sering dipakai bersama. Satu klik untuk memuat seluruh kombinasi.

          💡 Role mendefinisikan siapa AI-nya. Context memberikan apa yang diketahui. Preset menyimpan kombinasi favorit.

          🔀 Template Output

          Markdown Header — Format default. Mudah dibaca manusia. Dipisahkan garis horizontal.

          XML Tags — Struktur terperinci dengan tag. Cocok untuk AI yang merespons baik dengan struktur XML.

          Compact — Format padat tanpa whitespace berlebih. Cocok untuk menghemat token.

          💡 Default ke Markdown. Pakai Compact jika mendekati batas token.

          📊 Estimasi Token

          Bar anggaran menunjukkan posisi token relatif terhadap budget (default 8.000):

          🟢 0–50% — Aman, masih banyak ruang.

          🟡 50–80% — Pertimbangkan memangkas konten.

          🔴 80–100% — Hampir penuh, potong yang kurang penting.

          ⚫ >100% — Melebihi batas, output mungkin dipotong AI.

          💡 Akurasi ±20%. Beri buffer 10–15% dari batas AI yang kamu gunakan.

          📦 Export & Import

          Export JSON (Ctrl+Shift+E) — Backup semua data ke file .json.

          Export Markdown (Alt+D) — Unduh hasil merge sebagai file .md.

          Import JSON (Alt+I atau drag-drop) — Pilih mode Merge (tambah baru) atau Replace (timpa semua).

          Import Markdown (drag-drop .md) — Diimpor sebagai Context baru.

          💡 Backup secara berkala! Simpan file backup di cloud storage.

          💡 Tips Umum

          • Pisahkan Context per topik untuk kemudahan pencarian.

          • Simpan Role yang sering dipakai sebagai reusable asset.

          • Gunakan Preset untuk alur kerja rutin (code review, debugging, dokumentasi).

          • Gunakan mode preview Rendered untuk memeriksa tampilan sebelum paste.

          • Pencarian (Ctrl+F) mencari di judul dan isi konten.

          🔐 Keamanan & Privasi

          Data hanya disimpan lokal di browser kamu. Tidak dikirim ke server mana pun.

          Jangan simpan API key atau kredensial di dalam Context.

          Hanya import file dari sumber terpercaya.
