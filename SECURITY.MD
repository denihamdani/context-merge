# Security Policy

## Supported Versions

Version 0.2.0 — aktif.

## Reporting a Vulnerability

Jika menemukan celah keamanan:

1. Jangan buka public issue.
2. Kirim laporan ke: [email kamu]
3. Sertakan: deskripsi, langkah reproduksi, versi aplikasi.
4. Respons: maksimal 7 hari kerja.

## Security Documentation

Dokumen lengkap mengenai model proteksi dan klasifikasi risiko ada di docs/keamanan.md.

## Scope

Aplikasi statis tanpa server. Cakupan keamanan terbatas pada
client-side (XSS, import data, penyimpanan lokal).
